# 🍔 Full-Stack Food Delivery Application

![Node.js](https://img.shields.io/badge/Node.js-18+-339933.svg)
![React](https://img.shields.io/badge/React-18+-61DAFB.svg)
![MongoDB](https://img.shields.io/badge/MongoDB-NoSQL-47A248.svg)

A modern, responsive full-stack web application for online food ordering, featuring real-time cart management, user authentication, and order tracking.

## 🚀 Key Features
- **Responsive Frontend**: Built with React for seamless user interactions and dynamic menu browsing.
- **Robust Backend API**: Handles user authentication, order processing, and payment gateway integration.
- **Real-Time Order Tracking**: Keep users updated on meal preparation and delivery status.

## 🛠️ Quickstart & Local Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Sxmxxrth/food-delivery-app.git
   cd food-delivery-app
   ```
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Start the application**:
   ```bash
   npm start
   ```
